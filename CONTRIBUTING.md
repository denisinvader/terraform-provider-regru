# Contributing

Bug reports and feature requests are welcome; you do not need to contribute code.

## Report a bug

1. Search the existing issues for the same problem.
2. Open a **Bug report** and include the steps that reproduce it.
3. Include Terraform and provider versions, the operating system and architecture, and any relevant error messages.

Report one problem per issue. Include a minimal Terraform configuration and the commands needed to reproduce it. Remove Regru credentials, API keys, account details, and other secrets from configurations and logs before sharing them.

## Request a feature

1. Search the existing issues for the same request.
2. Open a **Feature request** and describe the Regru API capability or workflow you want the provider to support.
3. Explain what the provider does today and what behavior you expect.

You can suggest an implementation, but a detailed design is not required.

## Contribute code

For a small fix, open a pull request with a clear description and link the related issue if there is one. For a larger change, open an issue first so the scope can be discussed.

Include any checks you ran in the pull request description.

## Security and private information

Do not post credentials, API keys, account details, or other sensitive information in a public issue. Use the repository's **Security** tab to report vulnerabilities privately, if private vulnerability reporting is enabled.
